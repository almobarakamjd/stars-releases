الاقتراب منها من الأعلى مباشرة. تعديلات توازن الضربات الجماعية في المعارك الصغيرة (الضربة الجماعية، وضربة
الحارس، وسهم الطليعة). ودفعتا برومبتات خلفيات جديدة للبطاقات السوداء (فجر الصحراء وأيام البيت الخرب، وتكملة
الفصل الثاني).
